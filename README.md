# Paul Ragueneau - Portfolio

Un site portfolio moderne et réactif mettant en avant mon travail en tant que développeur web, avec expertise dans les microservices scalables et les technologies web contemporaines.

## 🚀 Fonctionnalités

- **Section Héro**: Introduction attrayante avec badges technologiques
- **Expertise Technique**: Vitrine des compétences et technologies maîtrisées
- **Projets Vedettes**: Showcase des projets clés et réalisations
- **Capacités**: Mise en avant des compétences fondamentales
- **Appel à l'Action**: Section de contact et engagement

## 🛠️ Stack Technologique

- **Framework**: [Next.js 16.1.0](https://nextjs.org/) - Framework React pour la production
- **Langage**: [TypeScript 5](https://www.typescriptlang.org/) - JavaScript type-safe
- **Styles**: [Tailwind CSS 4](https://tailwindcss.com/) - Framework CSS utilitaire
- **Runtime**: [React 19.2.3](https://react.dev/) - Bibliothèque UI
- **Linting**: [ESLint 9](https://eslint.org/) - Qualité du code

### Technologies Clés Présentées

- Next.js
- React
- TypeScript
- Docker
- PostgreSQL

## 📋 Composants

Le portfolio est composé des composants principaux suivants:

- `Hero.tsx` - Section d'introduction principale
- `TechnicalExpertise.tsx` - Vitrine des compétences
- `FeaturedProjects.tsx` - Portfolio de projets
- `Capabilities.tsx` - Compétences fondamentales
- `CallToAction.tsx` - Section de contact

## 🏃 Démarrage Rapide

### Prérequis

- Node.js 18+ installé

### Installation & Développement

1. Installer les dépendances:

```bash
npm install
```

1. Lancer le serveur de développement:

```bash
npm run dev
```

1. Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur

La page se mettra à jour automatiquement lors de vos modifications.

## 📦 Build & Production

Construire pour la production:

```bash
npm run build
```

Lancer le serveur de production:

```bash
npm start
```

## 🔧 Scripts Disponibles

- `npm run dev` - Lancer le serveur de développement
- `npm run build` - Construire pour la production
- `npm start` - Lancer le serveur de production
- `npm run lint` - Exécuter ESLint
